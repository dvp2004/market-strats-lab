# GMA-8B.0 Immutable GMA-6 Source-Pointer Intake Contract V1

GMA-8B.0 defines the manual immutable source-pointer intake required to resolve the inherited GMA-6 adjusted-price evidence.
No historical price panel, indicator, strategy signal, portfolio target, backtest result, strategy ranking, paper session, broker instruction, or real-money action is produced.
The GMA-8B provenance resolver remains fail-closed until an operator supplies exact local source paths and matching hashes.
Highest historical CAGR or Sharpe alone is not a selection rule.
No execution or promotion decision is produced.

## Template Boundary

The generated JSON is an empty operator template. Its eleven fields all contain `REQUIRED_MANUAL_ENTRY`; it is not a submitted intake and cannot pass validation. GMA-8B.0 never supplies or guesses paths.

An eventual submission must provide three absolute local Windows file paths outside every GMA-8 worktree, their exact SHA-256 hashes, all three frozen lineage hashes, an operator attestation, and a UTC creation timestamp. Directories, relative paths, inferred locations, fallback sources, and mismatched hashes fail closed.

The snapshot-manifest content must evidence the frozen GMA-6 snapshot and GMA-6B bundle lineage hashes. The normalized inventory must evidence the frozen normalized-bundle hash and must identify the exact submitted panel path and hash with the role `adjusted_price_source`.

## Dry Run

The only authorized real action in this phase is generation of the empty template and its deterministic requirement, dry-run, preregistration, lock, and execution records. The dry run does not hash or open a historical price panel. The next task is a separately bounded manual source-pointer submission validation; GMA-8B and GMA-8C remain blocked.
